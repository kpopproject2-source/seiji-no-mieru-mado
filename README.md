# 政治の見える窓

公約・確認できた活動・国内外支援の記録を、一次資料からたどる非公式のWebアプリです。

## 試験公開版

この版のデータ更新日：2026-10-31。各資料の確認日・対象時点はアプリ内で個別に表示します。候補者1284人、本人公約63件、党公約18件。候補者名簿の範囲と公約本文の掲載範囲は異なります。

法案提出、本人の行動、制度成立、施行、一部実施、実際の支払いを区別します。未確認は0円・未達・活動なしを意味しません。出典付きの要約であり、原資料も確認してください。

## 公開・保存について

HTML・JavaScriptと確認済みデータだけで動作します。GitHub Pagesの公開元をmainブランチのルートに設定して利用できます。フォロー・比較・文字サイズは利用中のブラウザーに保存されます。アプリから保存内容を外部へ送る機能はありません。

ブラウザーの設定を消すとフォロー等も消えます。公開先のホスティング事業者が扱うアクセス情報は、その事業者の説明をご確認ください。

## 誤りの指摘

このリポジトリのIssuesから、対象画面・出典URL・該当箇所を添えてお知らせください。個人情報やパスワードは投稿しないでください。指摘を受けた項目も、原資料との照合後に更新します。

原資料の全文PDFはこのリポジトリへ転載していません。出典はアプリ内およびcatalog.jsonに記録しています。
